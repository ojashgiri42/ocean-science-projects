This script downloads online data recorded by "Argo Floats".Argo floats usually have a cycle of 10days. The file format used is .nc(NetCDF) as it stores multidimensional data in a highly compressed way. We import urllib.request( to grab data from the internet) and use urlretrive to download the data. Xarray is the common organizer tool used to open .nc files. Index selection(isel(N_PROF=0) is done to just focus on the first dive (Profile 0 )) and use it as the new dataset for our analysis. We assign temperature and Pressure as the variables in x and y axis. We invert the graph as it makes graph easier to visualize.  The graph shows how water temperature decreases as the depth increases. This graphs will act as a baseline data to understand how much heat from the atmosphere is absorbed by the ocean, a primary indicator for climate change.
