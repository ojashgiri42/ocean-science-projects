This script reads NOAA OISST SST from the server via OPeNDAP and gives a colorful map of the ocean surface temperature(SST) of the east coast of USA using Cartopy. OPeNDAP[dodsC] lets us snippet the data we desire. The map shows the SST front associated with the Gulf Stream, which transports warm tropical water northward which are mostly responsible for global weather, hurricanes and marine ecosystems. 
Cartopy is used for map visualization which integrates with Matplotlib for geospatial data processing of earth's geography.
Data is used from NOAA (National Oceanic and Atmospheric Administration) website. [open_dataset(url)] opens the remote dataset, so only the requested subset is transferred rather than downloading the whole file.
We select a certain time for this visualization i.e 2023/01/01 and slice the world map to give us the lat and lon of US East Coast. [ ax ] defines us that we are projecting a map rather than just a image(axis) and [ projection=ccrs.platecarree() ] flatens out the round earth for the map. [cfeature.COASTLINE] draws a black outline where water meets the shore and [cfeature.LAND] helps to make the land stand out from the given ocean data . [cbar_kwargs] helps to create a legend for the color bar for the temperature
